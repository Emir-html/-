## Главные правила (действуют всегда)

1. Учебный контент (уроки, карточки, тесты) не менять, если я об этом не попросил. Новое — отдельными помеченными разделами.
2. Не использовать `Map` как конструктор — имя занято иконкой lucide-react; только `globalThis.Map`.
3. Хранилище в коде приложения — только `window.storage`. Новый ключ → правило слияния в обоих движках (jsx и progress-merge.js) + `BACKUP_KEYS`.
4. После каждой правки: сборка esbuild без ошибок, `npm test` зелёный, запись в changelog, git-коммит. Ни одной удалённой строки учебного контента (проверяй `git diff --stat` и `git diff | grep '^-' | wc -l`).
5. Экономика должна быть корректной на уровне жюри олимпиады — новая механика проходит `/econ-check` или субагента `economist`.
6. Ничего не отправлять в интернет (GitHub, деплой), не ставить глобальные пакеты и не удалять файлы вне проекта без моего «да» через AskUserQuestion.
7. Перед большой задачей — короткий план и вопрос «Начинаем?» через AskUserQuestion. Мелкие задачи — делай сразу.

### Шаг 2. Запуск в браузере на моём компьютере
- Подними Vite + React (`npm create vite@latest` или ручная настройка), установи зависимости приложения: `react`, `react-dom`, `lucide-react`, Tailwind (приложение использует классы Tailwind — проверь, нужен ли полноценный Tailwind или хватит CDN-скрипта `cdn.tailwindcss.com` в index.html; выбери самый простой рабочий вариант).
- Подключи шрифты Figtree и IBM Plex Mono (Google Fonts).
- Подключи `storage-shim.js` до рендера.
- `npm run dev` → приложение открывается на localhost, главный экран, тема, раздел «Перерыв → Лавка» работают.
- Известное ограничение: AI-проверка письменных ответов делает `fetch("https://api.anthropic.com/v1/messages")` без ключа — вне claude.ai это не сработает. Сделай так, чтобы при ошибке показывалось понятное сообщение «AI-проверка доступна только в версии на claude.ai», и спроси меня через AskUserQuestion, нужно ли подключать свой API-ключ через локальный прокси (по умолчанию — нет).
- Проверь перенос прогресса: импорт `data/progress-2026-09-24.json` через встроенную панель резервной копии должен пройти без ошибок.
- Ворота шага: я открываю localhost и вижу своё приложение. Спроси меня «Открылось / Есть проблема».

### Шаг 5. Документы этапов
- `docs/ROADMAP.md` — пять этапов из гайда с «воротами»:
  1. Концепция → ворота: дизайн-документ на одну страницу;
  2. Модель в цифрах → ворота: оптимальная стратегия выигрывает, «тупая» — нет, тесты зелёные;
  3. Серый прототип (экраны на серых блоках, 380 px) → ворота: после 20 минут игры хочется ещё один день;
  4. Анимация (≤ 300 мс, reduced motion, логику не трогать) → ворота: каждое решение игрока видно на экране;
  5. Дизайн (Claude Design → передача пакета сюда) → ворота: дизайн-система на всех экранах, баланс перепроверен.
  Отметь, где мы сейчас: этапы 2–3 частично сделаны, этап 1 (концепция на бумаге) пропущен.
- `docs/GAME_DESIGN.md` — шаблон одностраничного дизайн-документа: цель игрока, основной цикл, какие экономические идеи игрок «открывает сам» (со ссылками на ключи тем из CONCEPT_MAP), прогрессия, что точно не делаем.
