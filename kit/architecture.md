# МирСтади — архитектура (читать в начале каждой сессии)

## Что это
Однофайловое React-приложение `app/econ-trainer.jsx` (~46 900 строк, 348 уроков, Tailwind без JIT,
иконки lucide-react). Работает как артефакт Claude и как сайт (`mirstudy-web`, Vite).

## Разделы приложения
| Раздел | Компонент / данные | Префикс ключей хранилища |
|---|---|---|
| Экономика («Высшая проба») | MASTER_MAP, PROBLEMS, SM-2 карточки | без префикса: `review-state`, `topic-checked`… |
| Обществознание ЕГЭ (75 тем, 5 блоков) | SOCIAL_CURRICULUM, SOC*_* уроки | `social-*`, `ege-test-stats` |
| Финансовая грамотность | FINLIT_MAP (трек `finlit`) | `fg-*` |
| Основы бизнеса | BIZ_MAP (трек `biz`) | `bz-*` |
| Русский язык ЕГЭ | RUS_MAP (трек `russian`) | `ru-*`, `ru-taskstats` |
| Банк тестов ЕГЭ | TASK1_BANK | `testbank-stats` |
| Экономика тур №1 (пробный экзамен) | Q1_* уроки, TGloss | `q1-history` (массив попыток, ≤60) |
| Общее | таймер, план, тема | `time-v2`, `study-plan`, `ui-theme`, `backup-log` |

Треки ФГ/ОБ/Русский — один компонент, параметризованный `storeKey` (`fg`/`bz`/`ru`);
суффиксы: `-checked`, `-struggling`, `-teststats`, `-reviewed`.

## Библиотека компонентов уроков
TNote, TH2, TH3, TTerm, TCompare, TKey, TMistake, TCheck, TFormulaBox, TSteps, TFlow,
TMemo, Pill, TPyramid, TQuadrant; палитра COLORS. Бейджи глубины: зелёный ≥8000 симв.,
жёлтый 5000–7999, белый <5000.

## Хранение и перенос прогресса
- Всё хранится в `window.storage` (в артефакте) или в shim поверх localStorage (на сайте).
- **Резервная копия = `state/progress.json`**, формат v2:
  `{ app, version: 2, exportedAt, summary, data }`. `summary` — человекочитаемая сводка
  «предмет → изученные темы / трудные / точность тестов»; её достаточно, чтобы Claude
  понял прогресс, не разбирая сырые ключи.
- **Загрузка файла = слияние**, не перезапись. Правила — в `state/progress-merge.js`
  (единственное место, где они описаны). Кратко: SM-2 и задачи — поштучно по времени
  (`last`/`at`), отметки «изучено» — OR, счётчики — максимум, серия — поздняя дата,
  свои карточки — объединение по id, время — максимум по дням, `ui-theme` — локальная.
- В приложение движок встроен как `const ProgressMerge = (() => {...})()` патчем
  `tools/apply_progress_patch.py` (идемпотентен, работает на любой версии файла).

## Развёртывание (решение от 23.09 — заменяет план «Vercel + Supabase»)
Российский VPS + PocketBase (Vercel/Supabase блокируются в РФ). Офлайн-первый движок
синхронизации: localStorage → облако, last-write-wins **по ключу целиком**.
Пакеты: `mirstudy-web.zip` (исходники+тесты), `mirstudy-server.zip` (setup.sh).
**Известное ограничение и следующий шаг:** заменить в `syncEngine.js` сравнение по ключу
на `mergeValue(key, local, remote)` из `progress-merge.js` — тогда SM-2 с двух устройств
будет сливаться поштучно, а не затираться.

## Ловушка: имена иконок
Из lucide-react импортируется иконка `Map` — внутри файла она перекрывает встроенный `Map`.
В новом коде использовать `globalThis.Map`. Патч прогресса проверяет это автоматически.

## Правила правок большого файла
Python: прочитать → `assert s.count(anchor)==1` → заменить → записать →
`npx esbuild app.jsx --loader:.jsx=jsx --format=esm --outfile=/tmp/out.js` → в outputs.
Границу функции искать по её собственной закрывающей скобке, не общим шаблоном.

## Проверки после правок
`node test/progress-merge.test.mjs` (движок) и `test/app/` (все уроки, обход экранов,
сквозной тест прогресса через настоящий интерфейс) — см. test/app/README.md.
