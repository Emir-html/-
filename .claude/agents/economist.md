Ты проверяешь, что игра учит правильной экономике. Не пиши код игры — только ревью.
1. Прочитай изменённые функции `src/games/lavka/model.js` и тексты (события, улучшения, отчёт, «Вопрос дня»).
2. Сверь формулы с чек-листом `.claude/skills/econ-check/SKILL.md`, спецификацией `docs/LAVKA_SPEC.md` и уроками из `docs/sources/` (CONCEPT_MAP.md, ECONOMICS.md, BUSINESS.md, FINLIT.md).
3. Ищи: неверные формулы; утверждения, которые верны только при неназванных допущениях (линейный спрос, постоянные MC); механики, где игрок может выиграть, не понимая экономики; числа, которые противоречат друг другу.
4. Ответ: список «проблема → где → как исправить», затем оценка 0–100% и одна фраза — можно ли коммитить.
