# «Лавка» — дизайн-документ (одна страница)

Черновик 1 октября 2026, собран по `docs/LAVKA_SPEC.md`. ✅ — решено Миром, ❓ — ждёт решения.

## Роль в MirStudy
✅ **Главный тренажёр микроэкономики.** Игра проходит олимпиадную микроэкономику по главам (уровни ниже),
каждая механика ссылается на тему урока. Вход пока остаётся в разделе «Перерыв».

## Цель игрока
Вырастить лавку из 2 000 ₽: каждый день выбирать цену и закупку так, чтобы прибыль была наибольшей.
Внутренняя цель (её игрок не видит как задание): самому нащупать **MR = MC** и увидеть, как её сдвигают налоги, издержки, спрос и конкурент.

## Основной цикл (один день ≈ 1 минута)
1. **Утро.** Событие дня, прогноз из тетради → цена и закупка по каждому товару и точке.
2. **День.** Анимация 8:00–20:00: очередь, запас, «кончилось в ЧЧ:ММ».
3. **Вечер.** Отчёт: P&L, по товару — спрос, продано, дефицит, порча, |E|, CS, излишек продавца, DWL, вердикт MR vs MC.
4. **Решение.** Купить улучшение, взять кредит, ответить на «Вопрос дня» → следующее утро.

## Что игрок «открывает сам»

| --- | --- | --- |

| Выручка максимальна при |E| = 1, прибыль — при MR = MC | цена ↔ продажи в отчёте, тетрадь | `e-basic`, `e-properties`, `s-monopoly`, `pr-monopoly` |

## Подсказки
✅ Вердикт «MR vs MC» по истинным параметрам («оракул») — **только первая неделя уровня**. Дальше вердикт строится
по тетради игрока (его оценке спроса); без тетради или при малом числе наблюдений — только факты дня
(продано, дефицит, очередь, порча). На экзамене подсказок нет.

## Прогрессия: «Путь компании» (✅ решения из чата Claude, 1 октября)
Пять уровней = пять бизнесов; у каждого — **новый рычаг решения**. В финале все они — один холдинг.

| Уровень | Бизнес | Новый рычаг и идеи | Экзамен |
| --- | --- | --- | --- |
| 1 | Лавка у парка | цена и закупка: спрос, MR = MC, мощность и λ, налог t/2, потолок, дискриминация, Семён | обычный день / сдвиг спроса / политика |
| 2 | Ярмарка | **количество**: Курно с растущим n (P → MC), картель Семёна как повторяющаяся дилемма заключённого, лидерство Штакельберга | Курно n = 3, вход конкурента, картель |
| 3 | Сеть кофеен | **распределение между кухнями** (MC₁ = MC₂), U-образные AC, ступенчатые оптовые скидки, закрытие при P < min AVC, мощность и λ | две кухни + убыточная точка |
| 4 | Своё производство | **найм**: MRP_L = w, монопсония (MRC > w), МРОТ повышает занятость (зеркало потолка цены), аренда vs покупка через NPV | — |
| 5 | Холдинг | **капитал**: дивиденды дочек, NPV/PI при ограниченном капитале, аннуитет vs дифференцированный платёж, УСН 6% vs 15%, корреляция рисков дочек, франшиза, валютный риск | финал — продажа холдинга |

**Внутри уровня:** ≈ 3 недели (главы) + экзамен 3 дня. Глава открывается, когда прошла неделя **и** выполнена её
ключевая цель. «Оракул» — только первая неделя; дальше вердикт по тетради игрока, без тетради — только факты.

**Уровень 1 по главам** (✅ реализовано 1 октября):
| Глава | Дни | Что открывается | Ключевая цель для следующей |
| --- | --- | --- | --- |
| 1. Спрос | 1–7 | лимонад, круассан; жара, ливень, фестиваль; тетрадь, холодильник, помощник; оракул | «Чуйка монополиста» |
| 2. Издержки и налоги | с 8-го | мука, акциз, блогер; вывеска, оптовик, кофемашина | «Неделя в плюсе» |
| 3. Регулирование и рынки | с 15-го | потолок цен, Семён; морозильник, вторая точка | → экзамен уровня |

**Экзамен:** 3 дня по сценарию (обычный день / сдвиг спроса / политика), без подсказок. Случайность — генератор с сидом;
бот проигрывает те же сиды. Эффективность = прибыль игрока / прибыль бота. Пороги медалей калибруются по
**боту-ученику** (оценивает спрос МНК, как игрок): он должен получать ≈ серебро.

**Капитал между уровнями.** Ставка r — одна на уровень, в %/день; к ней привязан кредит. Окупаемость улучшений
с уровня 2 — 10–20 дней. Продажа дочки: покупатель видит только медаль, цена = аннуитет
D̄(медаль)·(1 − (1 + r)^−N)/r. Альтернатива — оставить дочку и получать дивиденд.

**Чтобы не было обидно:** каждый уровень стартует минимум со стандартного гранта; медали и «доска компании»
остаются навсегда; пройденный уровень можно переиграть в режиме «Сложнее».

Каждая новая механика проходит `/econ-check` и субагента `economist`.

## Связь с учёбой
✅ «Вопрос дня» берётся из карточек и тестов уроков MirStudy **по темам открытых глав** (✅ реализовано): тесты «верно/неверно»
(TEST_BANK), вопросы с вариантами (Q1_HARD, только микро), карточки (BUILTIN_CARDS) — как выбор из трёх, где неверные варианты —
ответы других карточек той же главы. Текущая глава ×2, слабые темы (лёгкость SM-2 < 2,2, просроченные, «трудные» карточки) ×3,
без повторов среди последних 30. Игра только читает банки и прогресс; свои 15 задач — часть банка (≈ 130 вопросов).

## Что точно не делаем
- Не меняем учебный контент уроков; игра только ссылается на темы.
- Нет реальных денег, рекламы, таймеров «вернись завтра» и наказаний за пропуск дней.
- Нет нелинейного спроса и случайности, которую нельзя объяснить экономикой: модель решается в уме.
- Нет сетевой игры и облака (пока игра живёт только на компьютере Мира).
- Визуальный стиль и анимации — только на этапах 4–5.
