## Переход с уровня 1

Открывается после экзамена уровня 1 с медалью (`levelFinish`). Покупатель лавки видит только медаль:

| Медаль | Дивиденд D̄, ₽/день | Цена продажи = D̄·(1 − 1,005⁻⁶⁰)/0,005 |
| --- | --- | --- |
| 🥇 | 1 500 | ≈ 77 600 |
| 🥈 | 1 100 | ≈ 56 900 |
| 🥉 | 700 | ≈ 36 200 |

- **Продать** — цена сразу; **оставить дочкой** — D̄ в день 60 дней. Старт — грант 5 000 ₽ + выбранное.
- Остаток на счёте приносит r = 0,5% в день (игровая ставка ≈ 500% годовых) — поэтому без вложений варианты равны по PV;
  продажа лучше, если деньги нужны сейчас на вложение доходнее r и кредита под r нет.

## Рынок

| Величина | Значение |
| --- | --- |
| Обратный спрос | P = A − B·Q, A = 200 (шок ±5% после выпечки), B = 1, Q — все пирожки на ярмарке |
| MC | 40 ₽ (у игрока со «Своей мукой» — 30) |
| Аренда | 800 ₽/день |
| Конкуренты | равновесие Курно для n фирм с учётом MC игрока: q_r = (A − 2c + c_игрока)/((n + 1)B) |
| Остаточный спрос | P = (A − B·Q₋) − B·q, MR = A − B·Q₋ − 2Bq, наилучший ответ q = (A − c − B·Q₋)/(2B) |
| Лидер (Штакельберг) | последователи отвечают на сегодняшний q: P = (A + k·c)/(k + 1) − B·q/(k + 1), q_L = (A + k·c − (k + 1)·c_игрока)/(2B) |
| Вердикт | первая неделя — по истинному спросу, дальше — по МНК «Q → P» игрока |

## Главы (по дням — рынок не ждёт)

| Глава | С дня | Что происходит | Цель (награда) |
| --- | --- | --- | --- |
| 1. Курно | 1 | дуополия с Семёном (Курно: по 53⅓, P = 93⅓) | «Равновесие Нэша» — наилучший ответ ±3 (1 500) |
| 2. Вход конкурентов | 8 | новичок входит, если ждёт прибыль Курно с n + 1 фирмами > аренды; сигнал — 3 дня прибыли у продавцов | «Длинный период» — вход прекратился, 3 дня в плюсе (2 000) |
| 3. Картель и лидерство | 15 | мэрия оставила 2 лицензии; Семён предлагает картель | «Верность картелю» 5 дней (2 500), «Лидер Штакельберга» (2 500) |

- Граница входа при равных MC: π(4) = 1 024 > 800, π(5) = 711 < 800 → **4 фирмы**; прибыль не нулевая (+224/день), а меньше,
  чем нужно ещё одному входящему.
- Картель: общий выпуск — монопольный при средней MC, квоты пропорциональны Курно. При равных MC — по 40, P = 120,
  прибыль 3 200 против 2 844 по Курно; обман (60) даёт 3 600 (+400) на день, наказание Курно 5 дней — −1 778.
  Устойчивость: δ ≥ (π_обман − π_картель)/(π_обман − π_Курно) ≈ 0,53; при r = 0,5% δ ≈ 0,995.

## Экзамен уровня 2

- Открыт в главе 3 с 22-го дня (`fairExamOpen`). 4 независимых дня на копии ярмарки (касса не меняется):
  1. **Курно, трое** — MC двух конкурентов случайны (36–44); 2. **вход дешёвого конкурента** — Семён 38–42, новичок 26–32;
  3. **картель** — обман засчитывается вместе с ценой наказания (5 дней Курно); 4. **лидерство** — Семён отвечает на твой объём.
- Объёмы конкурентов не показываются: известны число фирм и их MC — Нэш qᵢ = (A − (n + 1)·cᵢ + Σcⱼ)/((n + 1)B) (`fairNashCosts`).
- Оценка: среднее по дням (маржа игрока / маржа бота, тот же шок спроса), медали и пороги дня — как на уровне 1.
- Проверено тестами: бот — 100% 🥇; обман картеля — день < 70%; «всегда 53» — не выше бронзы.

## Слабые места

- «Всегда 53» близко к наилучшему ответу без вложений (−9%): в главах 1 и 3 это и есть равновесие дуополии.
- Конкуренты сразу в Нэше: динамики «подстройки» нет (сознательно — при n ≥ 3 наивные ответы не сходятся).
- Экзамен уровня 2 без калибровки ботом-учеником (ученику нужна только арифметика Нэша — он был бы 100%).
