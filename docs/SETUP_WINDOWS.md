# Как запустить MirStudy на Windows — от и до

Делается один раз примерно за 15 минут. Потом для запуска хватает части 4.

## Часть 1. Открыть PowerShell

1. Нажми клавишу **Win** (с флажком).
2. Напечатай `powershell`, нажми **Enter**.
3. Откроется окно с текстом `PS C:\Users\ИмяПользователя>`. Сюда вставляются все команды ниже:
   скопируй команду → щёлкни в окне **правой кнопкой мыши** (это «вставить») → **Enter**.

## Часть 2. Установить Node.js и Git (один раз)

1. Вставь и нажми Enter:
   ```
   winget install --id OpenJS.NodeJS.LTS -e
   ```
   Если спросит `Do you agree…` — напечатай `Y`, Enter. Если Windows спросит «Разрешить вносить изменения?» — **Да**.
2. Так же установи Git:
   ```
   winget install --id Git.Git -e
   ```
3. **Закрой PowerShell и открой заново** (иначе он не увидит новые программы).
4. Проверь:
   ```
   node -v
   git --version
   ```
   Должно быть что-то вроде `v22.20.0` и `git version 2.51...`.

**Если `winget` не найден:** скачай установщики вручную и жми «Next» до конца:
- Node.js — https://nodejs.org → кнопка **LTS**;
- Git — https://git-scm.com/download/win → «Click here to download».
Потом снова пункт 3–4.

## Часть 3. Скачать проект (один раз)

1. Перейди в «Документы»:
   ```
   cd $HOME\Documents
   ```
2. Скачай проект в папку `mirstudy`:
   ```
   git clone -b claude/inspiring-cray-gwn2yz https://github.com/Emir-html/-.git mirstudy
   ```
   Если репозиторий приватный, откроется окно входа в GitHub — нажми **Sign in with your browser** и войди.
3. Зайди в папку и установи библиотеки (1–2 минуты, много текста — это нормально):
   ```
   cd mirstudy
   npm install
   ```

**Если ошибка «выполнение сценариев отключено» (running scripts is disabled):** выполни один раз
```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
ответь `Y` и повтори `npm install`.

## Часть 4. Запустить (каждый раз)

1. Открой PowerShell и перейди в проект:
   ```
   cd $HOME\Documents\mirstudy
   ```
2. Запусти:
   ```
   npm run dev
   ```
3. Браузер сам откроет **http://localhost:5173**. Если не открыл — вставь этот адрес в браузер вручную.
4. **Не закрывай окно PowerShell**, пока пользуешься приложением. Остановить: в окне PowerShell **Ctrl + C**.

## Часть 5. Перенести прогресс с claude.ai (один раз)

1. В приложении нажми **«План подготовки»** (кнопка вверху справа).
2. Пролистай вниз до **«Резервная копия прогресса»** → **«Загрузить из файла»**.
3. Выбери файл `Документы\mirstudy\data\progress-2026-09-24.json`.
4. Должно появиться «Объединено: обновлено 8 разделов…», страница перезагрузится.

Если у тебя есть более свежий экспорт из claude.ai — загрузи и его: файлы сливаются, ничего не теряется.

## Часть 6. Получить обновления от Claude Code

Когда я сделаю новые изменения и запушу их, у себя выполни (при остановленном `npm run dev`):
```
cd $HOME\Documents\mirstudy
git pull
npm install
npm run dev
```

## Частые проблемы

| Что видишь | Что делать |
| --- | --- |
| `node` / `git` / `npm` «не является командой» | Закрой и открой PowerShell; если не помогло — переустанови (часть 2) |
| «running scripts is disabled» | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, потом `Y` |
| `Port 5173 is in use` | Где-то уже запущен `npm run dev` — закрой то окно или открой адрес, который показан в PowerShell |
| Белая страница | Нажми F12 → вкладка Console, пришли красный текст ошибки |
| AI-проверка ответов пишет «доступна только на claude.ai» | Так и задумано: локально проверки нейросетью нет |
