## Переход с уровня 2
После экзамена ярмарки с медалью (`levelFinish2`): продать ярмарку за аннуитет D̄·(1 − 1,005⁻⁶⁰)/0,005
(🥇 3 000 / 🥈 2 200 / 🥉 1 400 ₽/день) или оставить дочкой. Дочки прошлых уровней продолжают платить (холдинг).
Старт — грант 10 000 ₽ + выбранное; касса ярмарки уходит в архив. Остаток на счёте приносит r = 0,5%/день.

## Рынок и кухни
| Величина | Значение |
| --- | --- |
| Спрос | P = A − Q, A = 300 (глава 2 — 200), шок ±5% |
| Кухня на Садовой | MC = w + 20 + q, аренда 3 500, мощность 50; min AC при q ≈ √(F/b) ≈ 84 — за мощностью (AC в допустимой зоне падает) |
| Кухня на Заводской | MC = w + 40 + 0,5q, аренда 3 000, мощность 120; min AC при q ≈ 110 |
| Зёрна w | 20 ₽/чашка; в главе 3 при Q ≥ 120 — 14 ₽ на ВСЕ чашки |
| Оптимум | MR(Q) = MC₁ = MC₂ (бисекция по общему MC; кухня с MC(0) > MR не работает; кухня в упоре — λ) |
| Вердикт | первая неделя — по истинному спросу, дальше — по МНК «Q → P» только этой главы |
