## Модель

| Величина | Значение |
| --- | --- |
| Цена набора без сырья | p = 520 − 220 = 300 ₽; на Д19–21 — 400 (пик; в сценарии 380, но тогда оптимум остаётся 16 и цель ничего не проверяет); цех — ценополучатель |
| Выпуск | Q(L) = 14L − 0,25L², MP = 14 − 0,5L; L — целое |
| Предложение труда | w(L) = 600 + 50L: чтобы нанять L-го, платишь w(L) всем |
| Граница зарплаты | 1 400 ₽: с Д10, если принят договор Нины; с Д16 — МРОТ для всех |
| Постоянные | аренда цеха 3 000; котёл — аренда 8 000 или обслуживание своего 500 |
| Котёл | покупка 280 000, служит 48 дней, потом продаётся за 140 000 |

**Найм.** Все решения считаются по дискретным приростам: p·ΔQ L-го работника против роста расходов на труд на всех.

**Цена б/у котла:** V(n) = 7 500·a(r, n) + 140 000/(1 + r)ⁿ. Это то, что котёл сбережёт следующему владельцу.
- Поэтому решение принимается по PV на весь срок службы (48 дней): знак не зависит от дня покупки, а если покупать выгодно — выгоднее сразу (выигрыш 4 164 в PV дня покупки).
- Допущения: рынок б/у совершенный (покупатель с той же ставкой и альтернативой «аренда», без издержек сделки); новый котёл продаётся дешевле своей ценности в использовании (V(48) = 284 164 > 280 000) — игровая условность.
- В последний день уровня котёл продаётся по V(оставшийся срок).
- Это ответ на замечание экономиста о горизонте.

## Экзамен (3 сценария, числа по сиду)

**Параметры:** p = 250–550, предложение c + d·L, где c = 300–700, d = 40–90 (монопсонический L* ≥ 8).

| День | Сценарий |
| --- | --- |
| 1 | Монопсония |
| 2 | МРОТ всегда заметно меняет найм (|L − L_m| ≥ max(2, 15%)); в 30% вариантов он выше MRP(L_m) — занятость падает |
| 3 | Ставка 1,25 / 1,5 / 1,75% (купить) или 2,5 / 3 / 3,5% (аренда) — поровну и вдали от безразличия ≈ 2,06%; котёл + найм при МРОТ |

**Оценка дня.** 1 − 2·√(1 − маржа/маржа*) ≈ 1 − 2·|ΔL|/L*.
- L целое и точный ответ достижим, поэтому шкала вдвое строже, чем на уровнях 1–3 (при L* ≥ 8).
- Котёл — отдельный множитель 1 − 2·ΔPV/PV_min (переплата 28% → 0,44; 10% → 0,80).

**Проверка ботами (400 сидов):**

| Стратегия | Результат |
| --- | --- |
| «Всегда 14», «MRP = w», «игнорирует МРОТ» | серебро и выше ≤ 5% (тест) |
| «Котёл всегда аренда / покупка» при верном найме | золото примерно в половине попыток — бинарное решение угадывается, тест ≤ 60% |

**π̄_эт** — прибыль цеха в обычных условиях после МРОТ: 14 736 ₽/день (p = 300, 16 человек, котёл — лучший вариант при 2%); π̄_город = 0,908·π̄_эт = 13 381.
