## Модель

| Величина | Значение |
| --- | --- |
| Цена набора без сырья | p = 520 − 220 = 300 ₽; на Д19–21 — 380 (предновогодний пик); цех — ценополучатель |
| Выпуск | Q(L) = 14L − 0,25L², MP = 14 − 0,5L; L — целое |
| Предложение труда | w(L) = 600 + 50L: чтобы нанять L-го, платишь w(L) всем |
| Граница зарплаты | 1 400 ₽: с Д10, если принят договор Нины; с Д16 — МРОТ для всех |
| Постоянные | аренда цеха 3 000; котёл — аренда 8 000 или обслуживание своего 500 |
| Котёл | покупка 280 000, служит 48 дней, потом продаётся за 140 000 |

**Найм.** Все решения считаются по дискретным приростам: p·ΔQ L-го работника против роста расходов на труд на всех.

**Цена б/у котла:** V(n) = 7 500·a(r, n) + 140 000/(1 + r)ⁿ. Это то, что котёл сбережёт следующему владельцу.
- Поэтому решение принимается по PV на весь срок службы (48 дней) и не зависит от дня покупки.
- В последний день уровня котёл продаётся по V(оставшийся срок).
- Это ответ на замечание экономиста о горизонте.

## Экзамен (3 сценария, числа по сиду)

**Параметры:** p = 200–400, предложение c + d·L, где c = 300–900, d = 50–100.

| День | Сценарий |
| --- | --- |
| 1 | Монопсония |
| 2 | МРОТ. В 30% вариантов он выше MRP при монопсоническом найме — тогда занятость падает |
| 3 | Ставка 1,5–3,5%: котёл (аренда или покупка) + найм при МРОТ |

**Оценка дня.** 1 − 2·√(1 − маржа/маржа*) ≈ 1 − 2·|ΔL|/L*.
- Кривая прибыли по найму плоская, поэтому шкала вдвое строже, чем на уровнях 1–3.
- Неверный котёл вычитает свою переплату в дневном эквиваленте PV: ΔPV/a(r, 48).

**Проверка ботами (400 сидов):**

| Стратегия | Результат |
| --- | --- |
| «Всегда 14» | серебро и выше ≈ 3% |
| «MRP = w, без учёта MRC» | без серебра |
| «Оптимум, но игнорирует МРОТ» | бронза или серебро |

**π̄_эт** — матожидание прибыли эталона по распределению экзамена.
