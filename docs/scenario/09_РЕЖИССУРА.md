# Режиссура: кадры, анимация, ритм

Версия 1 · 2 октября 2026 · этап 5

Документ описывает **что игрок видит, в каком порядке и как долго**. Он опирается на существующие компоненты (`lavka-ui.jsx`): `LavkaAwning` (маркиза), `LavkaCard`, `LavkaEventCard`, `LavkaQuizCard`, `LavkaProductRow`, `LavkaDemandChart`, `LavkaProfitBars`, `LavkaReport`, `LavkaRun`, `LavkaStepper` и токены `COLORS` (onyx, paperDeep, sage, sageSoft, rust, rustSoft, amber, ink, inkSoft). Новые кадры и компоненты помечены **[новый]** и продублированы в `14_ПРЕДЛОЖЕНИЯ_К_МЕХАНИКЕ.md`.

## 0. Общие правила

| Правило | Значение |
| --- | --- |
| Ширина | от 380 px; одна колонка; поля 16 px; карточки на всю ширину; минимальная зона касания 44 × 44 px |
| Темы | светлая и тёмная; все цвета — токены; контраст текста ≥ 4,5:1; тёмная тема в мире — «вечер» (фонари в кадре дня) |
| Анимации | одно действие ≤ 300 мс; кривая ease-out; ничего не двигается дальше 24 px |
| `prefers-reduced-motion` | у каждой анимации есть статичный вариант: элемент появляется сразу (opacity 0 → 1 за 0 мс), счётчики показывают итог, «день» заменяется лентой из 4 кадров-состояний (8:00 / 12:00 / 16:00 / 20:00) с кнопкой «Дальше» |
| Цикл дня | ≈ 7 с при ×1 (как сейчас: шаг 0,012 каждые 90 мс), кнопки ×3 и «К итогам» сохраняются |
| Звук | нет. Пометки «🔈 на будущее» — только как идеи |
| Числа | IBM Plex Mono; ₽ через неразрывный пробел; минус «−» |
| Диалог | не больше 3 реплик на экран без действия игрока; каждая реплика ≤ 140 знаков; выбор — 2–3 кнопки в столбик |
| Портрет | эмодзи в круге 40 px (диалог) / 28 px (карточка события), подложка — пастельный цвет персонажа |
| Фокус | на каждом кадре один главный элемент (ниже отмечен ★) |

### Компонент диалога **[новый]** `LavkaDialogue`

Композиция (380 px): сверху портрет 40 px + имя (12 px, inkSoft) + прозвище в кавычках мелко; под ним «пузырь» реплики (LavkaCard, tint персонажа); под пузырём — кнопки ответа героя столбиком. Нажатие в любом месте пузыря — следующая реплика.

Анимация: пузырь — fade + подъём на 8 px, 180 мс; текст появляется целиком (без «печатной машинки» — она превышает 300 мс и мешает чтению); кнопки ответа — fade 120 мс после пузыря. Reduced motion: всё сразу.

Правило длины сцены: до 6 реплик — подряд; длиннее — с «паузой действия» (игрок делает ход: цена, выбор) в середине.

### Карточка урока **[новый]** `LavkaLessonCard` и карточка прототипа `LavkaProtoCard`

Появляются **после** озарения, в вечернем отчёте, под вердиктом. Свернуты в одну строку («💡 Ты это уже понял(а): MR = MC — открыть») — раскрываются по нажатию, 200 мс. Содержат: название идеи, 2–3 строки, формулу в одну строку, кнопку «Урок в MirStudy» (ключ темы). Карточка прототипа: силуэт в круге, имя, годы, 2–3 строки, подлинная цитата (если есть), пометка «Персонаж {имя} — вымышленный житель Кленовска».

## 1. Кадры уровня 1 (эталон для всех уровней)

### К-1. Выбор героя **[новый]**

- Композиция: маркиза (жёлто-белая) с названием «Лавка · Путь компании»; ниже 2 × 2 сетка карточек героев (эмодзи 48 px, имя, строка характера), пятая карточка «Свой герой» на всю ширину (поле имени, переключатель он/она); внизу кнопка «Начать» ★.
- Порядок появления: маркиза (0 мс) → карточки по одной с шагом 60 мс (fade + scale 0,96 → 1, 160 мс) → кнопка.
- Выбор: карточка получает рамку onyx, остальные тускнеют до 60% (120 мс).
- Reduced motion: всё сразу; выбор — только рамка.

### К-2. Утро

- Композиция сверху вниз: маркиза с датой и днём недели («Сб, 6 июня · день 6») и кассой ★ справа; карточка события (`LavkaEventCard`), если есть; карточка радио Лёвы (одна строка прогноза); строки товаров (`LavkaProductRow`: цена ±, закупка ±, подсказка Тетради, если куплена); «Вопрос дня» (записка от Веры, свёрнута); липкая кнопка «Открыть лавку» внизу ★.
- Порядок: маркиза → событие (slide-down 12 px, 220 мс) → радио (fade 150 мс) → товары (без анимации, чтобы можно было сразу действовать) → кнопка.
- Диалог утра (если есть сцена) идёт **до** строк товаров: `LavkaDialogue` поверх затемнённого фона (overlay 40%, 150 мс), по завершении overlay уходит.
- Изменение цены степпером: число «подпрыгивает» на 2 px (80 мс); если Тетрадь есть — её прогноз продаж пересчитывается с fade 120 мс.
- Reduced motion: без slide; overlay мгновенно.

### К-3. День (`LavkaRun`)

- Композиция: часы ★ 8:00 → 20:00 (крупно, моно), кнопки ×1 / ×3 / «К итогам»; полоса прогресса; полосы остатков по товарам; лента «покупателей» (эмодзи-лицо + товар или 💨); счётчики «Продано / Выручка / Ушли ни с чем».
- Новые биты **[предложение]**:
  - **Очередь**: когда спрос превышает мощность, перед лентой появляется счётчик «⏳ в очереди: N» (rust), а ушедшие получают 😕 вместо 💨. Появление счётчика — fade 150 мс.
  - **Даня**: если помощник нанят, в углу карточки эмодзи 🧑 «жонглирует» — три круассана по дуге (CSS-анимация 1,2 с, бесконечная, амплитуда 10 px); раз в день один «падает» и «ловится» (300 мс). Reduced motion: статичный 🧑🥐.
  - **Сюжетная вставка**: на Д6 в 14:00 (t ≈ 0,5) день ставится на паузу, показывается сцена «Очередь» (`LavkaDialogue`), затем день продолжается. Пауза — не больше одной за день.
  - **Мэр и флажки** (Д13): строка 🎩🚩 проходит по ленте один раз.
- Reduced motion: четыре статичных состояния (8:00, 12:00, 16:00, 20:00) с итоговыми числами на каждый момент, кнопка «Дальше».

### К-4. Вечерний отчёт (`LavkaReport`)

- Порядок появления (каждый блок — fade + 8 px, 160 мс, шаг 120 мс; общая длительность ≤ 1,2 с, нажатие пропускает):
  1. Прибыль дня ★ — крупно, счётчик «докручивается» от 0 за 300 мс (reduced motion — сразу итог).
  2. Строки P&L: выручка, закупка, акциз, постоянные издержки.
  3. По товарам: цена, хотели, продано, дефицит, очередь, порча, |E|, CS, PS, DWL.
  4. Вердикт: оракул Веры (Д1–7) или «по твоим данным» (с Тетрадью). Это единственное место, где персонаж оценивает решение.
  5. Лояльность (шкала 80–110%, стрелка изменения).
  6. Карточки урока и прототипа (свёрнуты).
  7. Новые цели и награды.
  8. Прогноз на завтра (вечерний эфир Лёвы) и кнопка «Следующее утро» ★.
- Вечерний диалог (если есть) — после блока 4, до блока 5.
- Особые состояния вердикта (тексты — `10_…`): λ > 0; цена на потолке; дефицит; порча; неэластичный участок.

### К-5. Тетрадь аналитика (`LavkaDemandChart`)

- Композиция: вкладки товаров; график ★ (точки наблюдений, линия D, линия MR, горизонталь MC, точка MR = MC; при λ > 0 — вторая горизонталь «MC + λ» пунктиром **[предложение]**); под графиком — «оценка: Q = α − β·P», прогноз продаж при текущей цене; список дней, исключённых как события.
- Анимация: при добавлении точки — «капля» (scale 0 → 1, 200 мс); линия перерисовывается morph 250 мс. Сцена «Церера» (Д3): линия впервые прорисовывается слева направо за 300 мс. Reduced motion: линия сразу.
- На 380 px график 348 × 220, подписи осей 11 px, точки 8 px, зона касания точки 32 px (подсказка «день 5: цена 52, хотели 57»).

### К-6. Магазин улучшений

- Список карточек; закрытые — серые с замком и строкой «откроется позже» (без даты — чтобы не спойлерить); новое открытие — карточка «подсвечивается» amber-рамкой 2 раза (2 × 300 мс). Покупка: карточка переворачивается на «урок» (lesson из кода) — fade-замена 200 мс.

### К-7. Экзамен **[новый]**

- **Вход**: полноэкранная карточка «Три дня без Веры» (маркиза сворачивается в тонкую полосу, фон чуть темнее), строки правил, кнопка «Готов(а)». Fade 250 мс.
- **Утро экзамена**: как К-2, но без записки «Вопрос дня», без подсказки оракула; в маркизе — счётчик «Экзамен 1/3» и силуэт Плотникова 🕴️ (статичный).
- **Вечер экзамена**: отчёт без вердикта и без карточек урока; вместо них — строка «Плотников записал».
- **Итог**: медаль ★ появляется scale 0,8 → 1 + fade, 300 мс; под ней эффективность (счётчик 300 мс), три строки «где потеряно» и кнопка «Разбор». Reduced motion: всё сразу.
- **Разбор**: три карточки-дня; в каждой «твой ход / ход эталона / разница в ₽» и одна фраза-урок.

### К-8. Продать или оставить **[новый]**

- Композиция: сцена `LavkaDialogue` (Плотников, Вера) → карточка решения: слева «Продать: {V} ₽ сейчас», справа «Оставить: {D} ₽ в день, {N} дней»; под ними кнопка «Посчитать» (раскрывает формулу аннуитета и поле ввода; после ввода — проверка) ★; две кнопки выбора.
- Анимация: карточки-варианты въезжают с двух сторон на 12 px (200 мс). После выбора невыбранная гаснет до 40%.

### К-9. Переход между уровнями **[новый]**

- Три экрана по нажатию: (1) итог уровня — медаль, прибыль, флаги-эпилоги одной строкой; (2) карта Кленовска: пять районов-плашек, река, мост; подсвечивается район следующего уровня (пульс рамки 2 × 300 мс); (3) короткая сцена-подводка (3–5 реплик).
- Маркиза меняет цвет на цвет нового уровня: cross-fade 300 мс.
- Reduced motion: без пульса и cross-fade.

## 3. Ритм

### Внутри дня (1,5–3 минуты)

| Фаза | Время | Напряжение | Что делает игрок |
| --- | --- | --- | --- |
| Утро: новость и сцена | 15–40 с | растёт (что случилось?) | читает, выбирает реплику |
| Решение | 20–60 с | пик выбора | ставит цену / объём / найм |
| День | 7 с (или 2 с на ×3) | ожидание | смотрит |
| Отчёт | 20–40 с | развязка | читает итог, вердикт |
| Карточка урока / ВД | 0–40 с | спад | по желанию |

Сессия «перерыва» 10–20 минут = 5–8 игровых дней: примерно одна сюжетная неделя. Каждая неделя заканчивается естественной точкой остановки (итоги недели, сцена-пауза в воскресенье).

### Внутри недели

Пн — тихий ввод · вт–чт — событие недели разворачивается · пт — выбор · сб — пик (выходные, очередь, праздник) · вс — пауза, итог, подводка к следующей неделе.

### Внутри уровня

| Неделя | Регистр | Плотность сцен |
| --- | --- | --- |
| 1 | Уют, обучение, оракул рядом | 1 сцена в день, короткие |
| 2 | Главный конфликт уровня | 1–2 сцены в день, одна длинная |
| 3 | Решение и последствия | 1 сцена в день, одна драматическая |
| Экзамен | Тишина | почти без реплик |
| Финал | Разрядка | 1 длинная сцена + выбор |

### Правило тишины

Не больше **двух диалоговых сцен на день** и не больше **одной длинной** (> 6 реплик). Если в день по календарю попадает больше — вторая переносится на вечер. На экзамене — одна реплика утром, одна вечером.

## 5. Доступность

- Все выборы доступны с клавиатуры (Enter — дальше, 1–3 — вариант ответа); порядок фокуса сверху вниз.
- Цвет не единственный носитель смысла: дефицит — rust + значок 💨, очередь — rust + ⏳, оптимум — sage + ✓.
- Эмодзи-портреты имеют текстовую подпись (имя) для экранных читалок; анимация дня дублируется итоговыми числами.
