# Тексты интерфейса

Версия 1 · 2 октября 2026 · этап 5

Формат: `ключ` — текст. Подстановки в фигурных скобках: `{P}`, `{N}`, `{имя}`. Род героя — разметкой `{м|ж}`: «Ты {поставил|поставила}». Числа — моноширинным шрифтом, ₽ через неразрывный пробел. Реплики персонажей из сцен — в файлах уровней; здесь — всё, что принадлежит интерфейсу, плюс вердикты, карточки событий, уроков и прототипов.

Правила тона: коротко; на «ты»; без восклицаний в отчётах; без оценки игрока («ошибка», «плохо») — только что произошло и что из этого следует.

## 4. Вердикты отчёта

Вердикт — одна строка под итогом по товару или решению. Дни 1–7: говорит Вера (истинные параметры). Позже: тот же текст с приставкой `lbl.byYourData`, если есть Тетрадь; без Тетради — только факты (продано, ушли, выбросил) без совета.

**Порядок проверки (первое сработавшее правило побеждает):**

1. Товар на потолке цены.
2. Дефицит (товар кончился до 20:00).
3. Очередь (мощность): λ > 0.
4. Порча > 10% закупки.
5. Цена против оптимума MR = MC + λ.

### Уровень 1

| Ключ | Условие | Текст (Вера) |
| --- | --- | --- |
| `v.cap.ok` | Цена = потолок, продано ≥ D(потолок) − 3% | Выше потолка нельзя — и не надо. Сходится |
| `v.cap.short` | Цена = потолок, закупка < D(потолок) | Выше потолка нельзя. А продать можно было больше: каждый стакан давал {cap} ₽ при закупке {c} ₽. Вези больше |
| `v.cap.below` | Цена < потолка (потолок ≤ P*) | Ты {поставил|поставила} ниже потолка. Зачем? До потолка — можно |
| `v.cap.capacity` | Цена = потолок, λ ≥ потолок − MC | На потолке и окошко полное. Остальные товары — дороже: место в окошке сегодня стоит {λ} ₽ |
| `v.short.price_ok` | Дефицит, цена в пределах 1,5 ₽ от P* | Цена правильная. Товара мало. Не цену трогай — закупку |
| `v.short.price_low` | Дефицит, цена < P* − 1,5 | Кончилось в {время}. И цена низкая, и товара мало. Начни с цены |
| `v.short.price_high` | Дефицит, цена > P* + 1,5 | Кончилось в {время} — но при такой цене и хотели немного. Сначала цена, потом закупка |
| `v.queue` | λ > 1,5 и цена ≤ P* без мощности + 1,5 | Очередь — это не похвала. {N} человек ушли. Место в окошке сегодня стоит {λ} ₽ |
| `v.queue.ok` | λ > 1,5 и |P − P*(λ)| ≤ 1,5 | Окошко полное, никто не ушёл зря. Сходится |
| `v.spoil` | Порча > 10% закупки | {Выбросил|Выбросила} {N}. Это {X} ₽ — тоже издержки |
| `v.low` | MR < MC + λ − 3 (цена ниже оптимума) | {Продешевил|Продешевила}. Последний {стакан|круассан} принёс тебе {MR} ₽, а стоил {MC} ₽: можно было продать меньше и дороже |
| `v.high` | MR > MC + λ + 3 (цена выше оптимума) | Дорого. Мимо прошло примерно {N} человек, которые купили бы дешевле — и тебе было бы выгодно |
| `v.ok` | |MR − MC − λ| ≤ 3 | Сходится |
| `v.inelastic` | |E| < 1, не на потолке | Ты на участке, где дешевле — значит меньше выручки. Поднимай цену: потеряешь мало покупателей, а получишь больше с каждого |
| `v.duel` | Действует «Семён» | Рядом Семён по {Pк} ₽. Твой лучший ответ сегодня был {BR} ₽ |

Запрещённые сочетания (из рецензии экономиста): при `v.cap.*` никогда не выводится «подними цену»; при дефиците никогда не выводится «снизь цену — продашь больше»; при λ > 0 никогда не выводится «MR ≈ MC — отлично», если MR заметно ниже MC + λ (цена слишком низкая для занятого окошка).

## 9. Карточки уроков

| Ключ | Название | Текст | Формула | Тема |

| `les.mrmc` | Последний стакан | Чтобы продать ещё одну единицу, цену снижают для всех, поэтому она добавляет к выручке меньше своей цены. Прибыль максимальна, когда эта добавка равна издержкам на единицу | MR = MC; P* = (A/B + MC)/2 | `s-monopoly` |
