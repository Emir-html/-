2. **Отнести экономисту** `14_ПРЕДЛОЖЕНИЯ_К_МЕХАНИКЕ.md` и `ПАРАМЕТРЫ.md` (как написано в README комплекта). В первую очередь — раздел «Что стоит обсудить с экономистом».
3. **Сверить ключи тем** с `econ-trainer.jsx`: 11 ключей с «?» и два названных в решениях (`i-asymmetry`, `p-multiplant`) — список в конце `11_…`.

## Что не сделано и чего я не проверял

- Сценарий не запускался в игре: модели уровней 2–5 есть только в `calc/`, в приложении их нет.
- Пороги медалей, доля дивиденда s = 0,3, «средние по городу» — заглушки до калибровки (П-7, П-26).
- Раскадровка уровней 2–5 короче уровня 1: у каждого дня есть событие, расчёт, ключевая реплика и озарение, а полные диалоги даны для 5–9 главных сцен уровня. Проходные дни можно дописать по тому же образцу.
- Реплики героя — 2–3 варианта без разбивки по четырём характерам (Ника, Глеб, Василиса, Тимофей): окраска по характеру описана правилом в `02_…`, отдельные тексты на каждого не написаны.
- Налоговые правила (УСН) даны упрощённо; перед выпуском сверить с действующими.
