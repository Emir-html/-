# «Лавка» — спецификация текущей версии

Снимок на 1 октября 2026 (econ-trainer__17_.jsx). Код: `src/games/lavka/model.js` (логика), `src/games/lavka/ui.jsx` (экраны). Это описание того, что уже работает, а не дизайн-документ будущей игры.

## Суть

Уютный тайкун в разделе «Перерыв» главного экрана MirStudy. Каждое утро игрок ставит цену и закупку по каждому товару, затем смотрит анимированный день (8:00–20:00) и вечерний отчёт. Цель игрока — прибыль; цель приложения — чтобы игрок сам нащупал MR = MC и связанные идеи олимпиадной микроэкономики.

## Модель рынка

| Величина | Формула / значение |
| --- | --- |
| Спрос точки на товар | Q = A − B·P, A = a · aMult(точка) · 1,15 (вывеска) · k · события, B = b · bMult(точка) · события |
| k | день недели × лояльность точки |
| Шум | реализованный спрос = round(E[Q] · U[0,92; 1,08]) |
| MC | закупка c (×0,85 с оптовиком) + акциз |
| Оптимум | P* = (A/B + MC)/2; при потолке между MC и P* — P* = потолок |
| MR при цене P | 2P − A/B |
| Эластичность | B·P/Q |
| Мощность | 120 покупателей/день на точку (+100 с помощником); при перегрузке продажи режутся пропорционально |
| Порча | всё непроданное выбрасывается; с холодильником 80% переходит на завтра |
| CS | S·(A/B − P) − S²/(2B) |
| DWL | TS(Q_эфф) − TS(S), TS(S) = S·(A/B − c) − S²/(2B), Q_эфф = A − B·c |

### Лояльность

Диапазон 80–110%, множитель к спросу. Если без товара ушли ≤ 3% желающих — +2 п.п., иначе −0,3 × доля ушедших. Делает дефицит скрытыми издержками (задача газетчика).

## События (одно за раз, с 3-го дня, шанс 45% утром)

| Событие | Эффект | Чему учит |
| --- | --- | --- |
| Жара | лимонад A ×1,5, мороженое ×1,6, кофе ×0,85; 1–2 дня | сдвиг спроса, P* растёт на половину роста резервной цены |
| Ливень | лимонад ×0,6, мороженое ×0,5, кофе ×1,3 | один фактор двигает спрос на разные блага в разные стороны |
| Фестиваль | все A ×1,3; 1 день | спрос вправо, эластичность в точке падает |
| Мука подорожала | круассан c +12; 2–3 дня | ΔP* = ΔMC/2 |
| Блогер | круассан A ×1,3, B ×0,75 | правило Лернера |
| Акциз 10 ₽ | случайный товар, t = 10 | перенос налога t/2 у монополиста |
| Потолок цен | cap = c + 0,55·(P* − c) | парадокс монополии: объём растёт, DWL падает |
| Конкурент «Семён» | 4 дня, товар у парка: Q = 0,55A − BP + 0,5B·Pк; Pк = наилучший ответ на вчерашнюю цену игрока | Бертран с дифф. товаром, сходимость к Нэшу |

## Прочее

- Старт: 2 000 ₽, день 1 = понедельник. Кредит 3 000 ₽ → долг 3 300 ₽, гасится половиной прибыли, доступен при кассе < 1 500 ₽ (до двух кредитов).
- Цели с наградами: первая прибыль (300), точная закупка (800), чуйка монополиста |MR − MC| ≤ 3 (1 500), парадокс потолка (2 000), пережил Семёна (2 000), дискриминация III степени (3 000), любимая лавка 105% (1 500), неделя в плюсе (2 500), 10 верных ответов (2 000), капитал 50 000, 30 дней.
- «Вопрос дня»: 15 задач в духе ВП, +400 ₽ за верный ответ, порядок вариантов перемешивается по дню.
- Отчёт дня: выручка, закупка, акциз, постоянные издержки, по товару — цена, спрос, продано, дефицит, очередь, порча, |E|, CS, излишек продавца, DWL, вердикт MR vs MC; лояльность; итоги недели; прогноз на завтра.
- Сохранение: ключ `lavka-save` в `window.storage`, правило слияния `newer` (по полю `at`), ключ в `BACKUP_KEYS`.
- Управление: Enter — открыть лавку / следующее утро.

## Известные слабые места (кандидаты для этапов 2–3)

- Поздняя игра разгоняется слишком быстро: при оптимальной игре касса > 300 000 к 40-му дню, а целей и трат после второй точки нет.
- Вердикт MR vs MC в отчёте опирается на истинные параметры — игрок получает «подсказку оракула»; стоит решить, оставлять ли это.
- Мощность и лояльность пересекаются: у оптимальной стратегии лояльность парка иногда падает из-за очереди, а не дефицита.
- Нет кривой сложности: все механики доступны с первых дней.
- В Вопросе дня 15 задач — по кругу через 15 дней.
